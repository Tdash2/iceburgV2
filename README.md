# Iceburg V2

A rewrite of the original iceburg. Live Production Control Web Interface. Iceburg is a C# based web GUI for controlling broudcast hardware. 

Iceburg is an acronym that stands for 
I ntegrated
C ross
E cosystem 
B roadcast
U ser defined 
R elationship based
G raphical user interface

This acronym explanes what Iceburg does. It is a cross product control interface. 


Below is a list of currently supported devices:
+ Behringer X32, X32 Compact, X32 Rack and X32 Producer 
+ Blackmagic Design Videohub
+ (Supported in V1 not in V2) Blackmagic Design Videohub Smart Control (40 button)
+ (Supported in V1 not in V2) Blackmagic Design Videohub Smart Control Pro (48 button)
+ (Supported in V1 not in V2) Cobalt Digital TOPAZ 9905-MPx
+ (Supported in V1 not in V2) Blackmagic Design SmartScope Duo
+ VMIX (Tally Only)
+ Symetrix DSP (logic Inputs Only)
+ Tally Iceberg IO Devices (GIP, GPO and TSL 3.0)
+ (Supported in V1 not in V2) ZowieTek 4k POV Camera
+ AJA FS-2 Frame Synchronizer and Converter
+ AJA FS-4 Frame Synchronizer and Converter
+ (Supported in V1 not in V2) Magewell Pro Convert for NDI® to SDI
+ (Supported in V1 not in V2) Aqua Streams Software Playback
+ (Supported in V1 not in V2) Open Matrix
